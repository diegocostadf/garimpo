# Segurança

Encontrou uma falha de segurança no Garimpo? Avise de forma privada, para que dê tempo de corrigir antes de o problema ficar público. Abra um aviso privado em **Security > Advisories** no repositório do projeto, com os passos para reproduzir e a versão afetada.

Não abra issue pública para falhas de segurança.
